Privacy policy

ChatGPT MultiChat Monitor

This page explains what the extension accesses, what it stores locally, and what—if anything—it sends over the network.

Effective: 19 September 2026 · Applies to ChatGPT MultiChat Monitor v0.3.0 and later unless updated.

Summary

ChatGPT MultiChat Monitor is local-first and does not use telemetry. It does not send conversation text, prompts, chat titles, aliases, activity history, or browsing activity to the developer or to an analytics service.

The extension runs its monitoring logic on chatgpt.com. A small request to GitHub's public releases API may be made at most once every 24 hours to check whether a newer stable version is available.

What the extension accesses

The extension needs to observe parts of the ChatGPT web interface in order to provide its user-facing monitoring features.

  • Generation state: visible interface signals are used to determine states such as Working, Done, Retry needed, Needs attention, Error, Stopped and Idle.
  • Prompt draft state: the extension checks whether the visible ChatGPT prompt composer contains unsent text so it can show Draft instead of Idle.
  • Latest assistant response tail: when generation finishes, a short tail of the latest assistant response may be inspected locally to make the optional Needs attention classification.
  • Open ChatGPT tabs/windows: tab metadata is used to show the monitor and switch to the selected conversation.

These accesses are used only to provide the extension's single purpose: monitoring and navigating active ChatGPT conversations across open browser tabs and windows.

What is stored locally

The extension may store the following in the browser's extension storage on your device:

  • Extension settings such as compact mode, sound choices and volume.
  • Per-chat aliases, pinned/hidden preferences and manual ordering.
  • A small recent-activity history containing a chat title, state and timestamp. It is capped at 100 events and 24 hours.
  • Update-check timestamps, the latest known stable version and a dismissed-version marker.
  • A one-time acknowledgement state for the What's new notice after an extension update.

Conversation bodies and prompt text are not stored in the recent-activity history.

Network requests and third parties

GitHub

The background service worker may request the public latest-release endpoint for JoelMomo/chatgpt-multichat-monitor at most once every 24 hours. The request is used only to detect whether a newer stable release exists.

The extension does not add conversation data, prompt text, chat titles, aliases or activity history to that request. As with ordinary web requests, GitHub may receive standard connection metadata such as an IP address and user agent under GitHub's own privacy practices.

Other services

The extension does not use analytics, advertising networks, data brokers, telemetry backends or a developer-operated collection server.

Data sharing and sale

The developer does not sell user data. The extension does not transfer ChatGPT conversation content or locally stored monitor data to advertisers, data brokers or other third parties.

Chrome Web Store Limited Use

The use of information received through browser permissions is limited to providing and improving the extension's disclosed single purpose. The extension does not use such information for personalized advertising or creditworthiness, and does not permit humans to read user data collected through the extension.

The use of information received from Google APIs, if any Google API access is introduced in the future, will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Permissions

  • storage — stores extension settings and the local metadata described above.
  • tabs — discovers and focuses open ChatGPT tabs/windows and reads the URL/title metadata needed to identify them.
  • scripting — reinjects the monitor into already-open ChatGPT tabs after the extension is installed or reloaded.
  • offscreen — plays local notification sounds in Manifest V3 without keeping an unnecessary visible page open.
  • https://chatgpt.com/* — limits the content script and page access to ChatGPT.

Your controls

You can clear recent activity, aliases, pins, hidden-chat state and manual ordering from the extension popup. Browser extension storage is removed when the extension is uninstalled, subject to the browser's own storage behavior.

You can also disable sound alerts, hide the floating monitor or remove the extension at any time through your browser's extension manager.

Security and remote code

ChatGPT MultiChat Monitor uses Manifest V3 and does not download or execute remotely hosted JavaScript or other remote executable code. Included notification sounds and extension code are packaged with the extension.

Changes to this policy

If the extension's data practices materially change, this policy will be updated to reflect the new behavior and the relevant store disclosures will be updated as required.
